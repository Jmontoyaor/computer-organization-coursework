# Computer Organization Coursework

Estructuras Computacionales - proyectos y ejercicios del curso.

El curso trabaja sobre distintas arquitecturas y plataformas, que se irán
integrando a este repositorio a medida que avance:

- **Código ensamblador:** RISC-V (RV32I) y ARM.
- **FPGAs:** Tang Primer 20K.
- **Microcontroladores y placas:** ESP32, STM32 Nucleo, Raspberry Pi.

## Proyectos

- [`first-assembly-program-morse`](first-assembly-program-morse/): primer programa
  en ensamblador del curso — una baliza Morse en RISC-V (RV32I) sobre la FPGA Tang
  Primer 20K, que enciende los 4 LEDs a la vez.
- [`hidroponia-esp32`](hidroponia-esp32/): monitor de variables de cultivos
  hidropónicos (pH, temperatura, TDS/EC, nivel de agua) sobre ESP32, con dashboard
  web en tiempo real.
