# Multi-Function Shield: Super Mario theme (STM32)

Bare-metal ARM assembly program for the NUCLEO-L476RG board with the Arduino
Multi-Function Shield: the buzzer plays the Super Mario Bros main theme and the
4-digit 7-segment display shows the frequency (Hz) of the note being played.

The tone is generated in hardware: TIM2 drives a 50 % square wave on PB3
(`ARR = 4 000 000 / f - 1`, `CCR2 = ARR / 2`, 4 MHz MSI clock, no prescaler), so
changing the note only means rewriting two timer registers. The CPU handles the
score timing and multiplexes the display through the shield's 74HC595 shift
registers.

## Files

- `Src/main.s` — the program: clock and GPIO setup, TIM2 PWM configuration, the
  score as a table of (frequency, duration) pairs, and the display routines.
- `Src/syscalls.c`, `Src/sysmem.c` — minimal newlib stubs generated by STM32CubeIDE.
- `Startup/startup_stm32l476rgtx.s` — vector table and reset handler.
- `STM32L476RGTX_FLASH.ld` — memory layout (1 MB flash at `0x08000000`, 96 KB RAM).
- `Makefile` — `make` builds, `make flash` programs the board over SWD, `make clean`
  removes `build/`.
- `.vscode/` — Compile / Flash / Clean buttons and an ST-Link debug configuration
  (Cortex-Debug).
- `informe/` — lab report (LaTeX source and PDF): flowcharts, wiring diagram,
  code walkthrough and possible improvements.

## Shield connections

| Function | Arduino pin | Nucleo pin |
|---|---|---|
| Buzzer (TIM2_CH2, AF1, active low) | D3 | PB3 |
| LEDs D1–D4 (active low) | D13, D12, D11, D10 | PA5, PA6, PA7, PB6 |
| 74HC595 latch | D4 | PB5 |
| 74HC595 clock | D7 | PA8 |
| 74HC595 data | D8 | PA9 |

## How to build

Uses the GNU toolchain and STM32CubeProgrammer bundled with STM32CubeIDE 2.2.0,
expected at `~/st/stm32cubeide_2.2.0`. For another location:

```sh
make CUBEIDE=/path/to/stm32cubeide_2.2.0
make flash CUBEIDE=/path/to/stm32cubeide_2.2.0
```

The debug configuration in `.vscode/launch.json` uses the same default location.
