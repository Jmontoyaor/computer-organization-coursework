Type 'help' for the command list.
> help
  help                           list commands
  status                         clock, PWM, mode and button summary
  frequency                      PWM frequency read from the timer
  duty                           PWM duty read from the timer
  set frequency <1-100000>       change PWM frequency (Hz)
  set duty <0-100>               fixed duty (%), manual mode
  set brightness <0|20|..|100>   brightness level through the curve
  set curve <linear|gamma>       brightness to duty curve
  fade <linear|gamma|off>        sweep brightness 0-100-0 %
  pwm <on|off>                   enable or force the output low
  clock                          RCC configuration decoded from registers
  mco <on|off>                   SYSCLK/16 on PA8 for the logic analyzer
  timer                          timer mode, polarity and registers
  button                         button state machine counters
  adc                            VDDA and temperature (internal ADC channels)
  radio                          read SX1276 registers over SPI1
